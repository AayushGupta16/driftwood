# Production plan

1. Add the admin-only `/dashboard/agents` route and existing dashboard chrome.
2. Poll one admin API payload every 15 seconds.
3. Render active agents in a three-column grid and paused agents in an archived drawer.
4. Add health 1–4, pause/archive, restore, status refresh, output links, and detail view.
5. Cover loading, empty, stale, invalid, error, and mutation states.
6. Build, lint, inspect desktop/mobile, and ship through `main`.
