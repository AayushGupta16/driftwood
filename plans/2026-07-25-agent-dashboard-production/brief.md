# Agent dashboard production brief

- Type: admin dashboard, generic tier, no marketing intent
- Job: let Aayush understand what every customer agent is doing at a glance
- Audience: Driftwood administrators arriving from the existing dashboard
- Primary actions: inspect an agent, set customer health, pause/archive, restore, refresh status
- Success: “What is happening with Autosana?” is answerable from one card in under five seconds
- Vibe: minimal, operational, calm
- Constraints: preserve Driftwood dashboard tokens and typography; no Mastermind; no decorative effects; Slack remains available

The approved source is `../../../mockups/agent-dashboard-lofi-v2.html` plus the conversation research in `../../../plans/2026-07-25-agent-dashboard-v2/`.
